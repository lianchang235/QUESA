STM32 推进器与舵机控制固件 README
 
项目简介
 
这是一个基于STM32 HAL库开发的嵌入式控制固件，专为多推进器水下机器人设计。固件通过串口与上位机进行双向通信，接收上位机发送的推力和舵机角度控制指令，同时实时回传系统运行状态和传感器数据。集成了INA226电流电压功率传感器，实现对系统功耗的精确监测。
 
核心功能
 
- 4路无刷推进器的精确推力控制
- 1路舵机的角度控制接口
- 基于帧头+和校验的可靠串口通信协议
- 推力到PWM占空比的非线性映射与线性插值
- INA226传感器数据采集与处理
- 周期性遥测数据回传
 
通信协议
 
- 第22字节：校验和，为前22字节所有数据的累加和
 
上行遥测帧（下位机 → 上位机）
 
帧总长度为55字节，由 UP_FRAME_LEN 宏定义，回传周期为100ms，由 TELEMETRY_PERIOD_MS 宏定义，数据按以下顺序排列：
 
- 第0-1字节：帧头，固定值为 0xAF 0xFA 
- 第2-5字节：系统电流值，单精度浮点数类型，单位为安培(A)
- 第6-9字节：系统总线电压值，单精度浮点数类型，单位为伏特(V)
- 第10-13字节：系统功率值，单精度浮点数类型，单位为瓦特(W)
- 第14-29字节：4个推进器的目标推力值，每个推力占4字节，单精度浮点数类型，单位为牛顿(N)
- 第30-45字节：4个推进器的实际PWM占空比，每个占空比占4字节，单精度浮点数类型，单位为百分比(%)
- 第46-53字节：4个定时器实际输出的PWM比较值，每个比较值占2字节，无符号16位整数类型
- 第54字节：校验和，为前54字节所有数据的累加和
 
推进器控制逻辑
 
1. 单位转换：将上位机发送的推力值（单位：N）转换为克力（g），转换系数为 102.0f 
2. 非线性映射：使用预定义的30点映射表将推力值转换为PWM占空比
3. 线性插值：对于映射表中没有的中间值，采用线性插值计算得到精确的占空比
4. 限幅处理：超出映射范围的推力值会自动限幅到映射表的最大或最小值
5. PWM转换：将计算得到的占空比转换为定时器比较值，输出到TIM2的4个通道
 
映射表参数
 
- 占空比范围：6.0% ~ 8.9%
- 推力范围：-780g ~ 1250g
- 映射点数：30个
- 中立点：7.5% 对应 0g 推力

代码结构
 
全局变量
 
-  rx_buf[23] ：串口接收缓冲区，用于存储逐字节接收的数据
-  frame_buf[23] ：完整控制帧缓冲区，用于存储校验通过的完整控制帧
-  rx_len ：当前已接收的字节数
-  frame_received ：帧接收完成标志，当接收到完整且校验通过的帧时置1
-  thrust[4] ：存储4个推进器的目标推力值
-  servo_angle ：存储舵机的目标角度值
-  duty_table[30] ：PWM占空比映射表
-  force_table[30] ：推力映射表，单位为克(g)
 
核心函数
 
-  calc_checksum() ：计算数据帧的和校验值
-  parse_down_frame() ：解析下行控制帧，提取推力和舵机角度数据
-  thrust_to_duty() ：将推力值转换为对应的PWM占空比
-  duty_to_pwm_compare() ：将PWM占空比转换为定时器比较值
-  send_up_frame() ：组装并发送上行遥测数据帧
-  HAL_UART_RxCpltCallback() ：串口接收中断回调函数，实现逐字节帧解析
